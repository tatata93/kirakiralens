最短ルート

まず1本、解析できる状態まで進める

KiraKiraLensは、中央のレンズ構成図を触って設計します。数値を変えただけでは重い性能計算を始めません。構成を作り、一次計算を確認し、必要なときだけ性能評価を実行します。

  1. 仕様を決める上部で焦点距離、開口、BFL、最大径を設定します。最初は50 mm、F/4のプリセットで構いません。
  2. 構成を作る左のカタログで部品を選び、構成図の挿入位置を右クリックします。レンズ本体の右クリックで置換や反転ができます。
  3. 間隔を合わせる構成図下の数値欄で空気間隔とBFLを調整します。曲面同士が重ならない距離を確保します。
  4. 一次計算光学計算または F5 を押し、EFL、BFL、F値と光線経路を確認します。
  5. 性能解析性能評価を開いて解析実行を押します。中心だけでなく70%像高と隅を見ます。
  6. 保存するファイル → 保存で .kklens として保存します。自動設計の前にも一度保存します。
最初に覚える違い 上部の光学計算は焦点距離や光線経路を確認する軽い一次解析です。性能評価 → 解析実行はMTFや各種収差を求める重い計算です。

画面の見方

上部: 設計全体

保存、元に戻す、光学計算、性能評価、像面・光線条件、自動設計があります。焦点距離、開口、BFL、最大径もここで指定します。

左: レンズカタログ

メーカー、形状、硝材、外径、有効径、EFLなどで市販品を絞ります。選択した部品が、挿入・置換の対象です。

中央: レンズ構成図

面、レンズ本体、空気間隔、像面をクリックします。右クリックで、その場所に合う操作が出ます。

右: 選択項目と一次解析

選択中のレンズや面を数値編集します。下部には実際に計算されたEFL、BFL、F値、画角などが表示されます。

図が小さくなったとき: メニューの設計 → 全体表示を使います。細部はホイールで拡大し、ドラッグで移動できます。

市販レンズを探して使う

候補が多すぎるとき

  1. 上部で目標の焦点距離、F値、最大径を先に決めます。
  2. カタログの撮影用絞込を押します。必要な入射光束を通せる外径が下限として入ります。
  3. 正レンズ / 負レンズと形状を選びます。型が決まっている場合は、各位置に必要な符号を先に合わせます。
  4. 必要ならメーカー、硝材、コーティング、CA、EFL範囲、波長で絞ります。
  5. 表の行を選ぶと、型番、外径、CA、EFL、BFL、硝材、対応波長が下に表示されます。
外径とCAは別物です 外径は部品そのものの直径、CAは光学的に使用できる有効径です。F/4の50 mmなら入射瞳径の目安は12.5 mmですが、斜め光束と配置によって各面で必要な径は増えます。CAがぎりぎりの部品だけで構成すると周辺光線が欠けやすくなります。
したいこと操作
末尾へ追加カタログで行を選択し、設計へ追加または行をダブルクリック。
レンズ間へ挿入カタログで行を選択し、構成図の空気間隔を右クリックして選択中のカタログレンズを挿入。
L1より物体側へ挿入構成図左端の「+」領域を右クリックし、選択中のカタログレンズをL1の前へ挿入。
今のレンズを置換先にカタログの行を選択し、置換したいレンズ本体を右クリックして選択中のカタログレンズに置換。
表裏を変更レンズ本体を右クリックしてレンズを反転。曲率符号、面順、硝材順もまとめて反転します。
「不完全データも表示」は閲覧用です 曲率、厚さ、硝材などが欠けた部品は、そのまま光学設計へ使用できません。検索結果を増やす目的以外では通常オフにします。

市販品の曲率や厚さを変更したい

カタログ品の処方は、型番との対応を守るため直接変更できません。対象レンズを選択してカスタム化を押すと、メーカー・型番から独立した編集可能なコピーになります。

間隔を正確に変えたい

構成図下の寸法欄、または間隔をクリックしたときに出る上部の間隔欄へmm単位で入力します。ドラッグは大まかな移動、数値欄は最終調整に使います。最後のレンズ後方の間隔がBFLです。

固定は何のためにあるか

固定した値は自動設計で変更されません。残したい曲率、硝材、径、レンズ順、空気間隔、像面位置を先に固定します。すべて固定すると自動設計の変更可能な値がなくなるため、必要な自由度は残します。

レンズのめり込み 頂点間隔が正でも、強い曲面の縁同士は交差することがあります。構成図を確認し、間隔を増やしてください。自動設計では変更範囲 → 最小すき間を0より大きくすると、曲面形状を含む接触判定が働きます。

像面・光線条件を決める

構成図のIMAGE線をクリックするか、上部の像面・光線条件を開きます。設定変更後は適用を押します。

像面

センサープリセットまたは幅・高さを設定します。フルフレームは36 × 24 mm、対角隅の像高は約21.63 mmです。像面を最良焦点へ追従をオンにすると、処方変更後に近軸最良焦点へ動きます。

開口

通常の写真レンズは像側F値が分かりやすい指定です。実測した物体側瞳径を合わせるなら入射瞳径、実絞りの穴寸法を固定するなら絞り面の半径を使います。

視野・光線

通常はセンサー対角の最大画角を使い、像高比0、0.7、1.0で中心・中間・隅を評価します。特定角度を調べるときは任意の半画角へ切り替えます。

波長

最初は写真光学で一般的なFraunhofer F-d-Cを使います。青486.13 nm、主波長の黄587.56 nm、赤656.27 nmです。撮像RGBや独自波長も設定できます。

速さと精度の調整 構成を試している間は光線数、スポット瞳リング数、横収差点数、曲線点数を少なめにします。候補を絞った後だけ増やし、性能評価の高精度で最終比較します。

性能を調べる

  1. 上部の性能評価を開きます。
  2. 検討中は解析品質: プレビュー、比較時は標準または高精度を選びます。
  3. 解析実行を押します。設計を変更しただけでは自動実行されません。
  4. まず概要で中心・70%・隅を比較し、悪い箇所を各グラフで診断します。

「よく写るレンズ」の見分け方

写真用レンズの良さは1個の数値では決まりません。次の条件を、同じセンサー、焦点距離、F値、物体距離、視野、波長、解析品質で比較します。

  • 目標のEFL、F値、BFLを満たし、全視野・全波長の光線が像面へ到達している。
  • MTFが中心だけでなく隅まで高く、TとSの低い側も保たれている。
  • スポットが小さく、青・緑・赤の分離が少ない。
  • 横収差と縦収差が0付近にまとまり、瞳の端で急に増えない。
  • 像面湾曲が小さく、TとSの隔たりも小さい。
  • 用途に対して歪曲が許容でき、グリッドが滑らかである。
  • レンズが衝突せず、有効径不足による周辺光線の欠けがない。
絶対値の合格線は用途で変わります 同じMTF40でもセンサーの画素ピッチ、現像、製造誤差、撮影距離、F値で見え方が変わります。まず現在案より良くなったかを固定尺度で比較し、最後に実際のセンサー要求へ照らします。

比較の正しい手順

  1. 比較する設計で像面・光線条件を同じにします。
  2. 性能評価の解析品質とMTF上限を同じにします。
  3. 各グラフ右上の軸範囲を押し、X軸・Y軸の自動を外して同じ最小・最大値を入力します。
  4. 中心だけでなく、同じ実像高mmの中間・隅を比較します。
  5. 改善した指標の代わりに別の指標が悪化していないか確認します。

各グラフの読み方と次の操作

MTF

良い傾向: 0から1の間で高いほどコントラストを保ちます。40 lp/mmまで高く、中心・中間・隅、T・Sの最低側が揃うほど安定しています。

悪いとき: 像面位置、F値、曲率、空気間隔を調整します。隅だけ悪い場合は絞り位置、像面湾曲、非点収差、径不足も確認します。

スポット

良い傾向: 点群、RMS半径、80%半径が小さく、波長色が重なります。Airy円に近い点群は回折限界に近い目安です。

悪いとき: 中心なら球面収差・色収差、隅ならコマ・非点収差・像面湾曲を他の図で切り分けます。

横収差

良い傾向: 瞳座標全体で光線誤差が0 µm付近に小さくまとまり、TとS、各波長が近接します。

悪いとき: 曲線形状から中心の球面収差、周辺のコマや非点を見ます。曲線が途中で切れる場合は径、絞り、レンズ衝突を確認します。

縦収差

良い傾向: 全瞳高の焦点ずれが0 mm付近で縦にまとまり、F・d・C線が近接します。

悪いとき: 同一波長の曲がりは縦球面収差、波長間の横ずれは軸上色収差です。自動設計の縦収差重視または縦収差RMSの重み・許容値を使います。

像面湾曲・非点収差

良い傾向: TとSの焦点ずれが0 mmに近く、2本の隔たりが小さい状態です。縦軸は像高比と実像高mmです。

悪いとき: 両線が同じ方向へ曲がるなら像面湾曲、TとSが離れるなら非点収差を疑います。絞り位置、正負のパワー配分、面の曲率を見直します。

歪曲・歪曲グリッド

良い傾向: 歪曲率が0%に近く、グリッドが理想格子へ滑らかに重なります。符号は樽型・糸巻型の方向を表します。

悪いとき: 絞り前後のパワー配分と絞り位置を調整します。歪曲は像の形を変えますが、それ単独ではぼけ量を示しません。

ペッツバール和

良い傾向: 一般に絶対値が小さいほどペッツバール像面は平坦方向です。対応する像面半径は絶対値が大きくなります。

悪いとき: 正負レンズの屈折力配分や高屈折率材を検討します。ただし0に近いだけで、非点収差やMTFが良いとは限りません。

画角・像高

良い傾向: 設定したセンサー全面が、必要な画角と実像高mmで評価されています。フルフレーム隅は約21.63 mmです。

悪いとき: 像高1.0が想定センサー隅と一致しない場合は、像面・光線条件のセンサー寸法と視野指定を見直します。

概要の値比較するときの見方
全像高の最低MTF40高いほどよい。最も悪い視野・方向を代表するため、中心だけ良い案を避けやすい。
隅のRMSスポット小さいほどよい。同じ条件・単位で比較する。
横収差RMS最大小さいほどよい。どの視野・波長で最大かを横収差タブで確認する。
隅の非点隔差絶対値が小さいほどT/S焦点差が小さい。
d線の縦球面収差 / 軸上色収差絶対値が小さいほどよい。符号より大きさと曲線形状を見る。
隅の歪曲 / グリッド最大歪曲絶対値が小さいほど形状再現が素直。用途によって許容範囲を決める。

自動設計を使う

自動設計は現在の設計を出発点にします。先に像面・視野・波長と、残したい部品や値の固定を済ませてください。実行中も元の設計は変更されず、候補を適用したときだけメイン画面へ反映されます。

今の形を整えたい

今の構成を調整を選択。固定していないカスタム曲率・厚さ・空気間隔・像面を連続最適化します。まず局所（速い）を使います。

同じ枚数で市販品へ置換したい

今の部品数で市販レンズを交換を選択。候補部品、順序、表裏を離散探索し、その後に空気間隔を詰めます。

枚数から自由に探したい

部品数も含めて自由探索を選択。最小・最大レンズ数、最大分割数、候補数、時間を現実的な範囲に絞って始めます。

既知の型から始めたい

古典型から市販レンズを探索を選択。Cooke Triplet、Tessar、Double Gaussから選び、型の正負配置を守ってカタログ候補を探します。

失敗しにくい設定順

  1. 1 設計目標: EFLと許容差、開口条件、BFL条件を入れます。Kマウント用で必ず確保したいBFLは以上と必須を使います。
  2. 2 変更範囲: 市販品探索の有無、メーカー、表裏・順序、レンズ数、最大分割数、最小すき間を設定します。
  3. 3 画質目標: 最初はバランス。解像を優先するなら解像重視、縦収差図を整えるなら縦収差重視を選びます。
  4. 最大時間・最大計算回数: 初回は短くして成立性を確認し、有望な条件だけ長くします。
  5. 候補比較: スコアだけで決めず、EFL、BFL、MTF40、RMSスポット、歪曲、全長、部品表、構成図を比較します。
  6. この候補を設計へ適用: 適用後、必ず性能評価を高精度で再実行します。
重み0は「評価しない」 たとえば歪曲の重みを0にすると、焦点距離とスポットが良くても歪曲の大きい案が上位に来ます。絶対に外せないEFL、BFL、全長、縦収差上限は必須も使います。
縦収差図を良くしたいとき 画質目標 → 縦収差重視を選ぶか、縦収差RMS（軸上・全波長）の相対重みを増やします。許容値を入力し、超過案を除外したい場合だけ必須条件をオンにします。強くしすぎると周辺MTFや歪曲が悪化するため、候補適用後に全タブを確認します。

特許実施例で動作を確かめる

  1. 上部の特許実施例を開きます。
  2. 収録された実施例を選び、記載値と注意事項を確認します。
  3. 設計へ読み込み、光学計算でEFLやBFLを確認します。
  4. 性能評価 → 解析実行で収差を確認します。
  5. 市販品化する場合は、左でカタログ品を選び、構成図の各レンズを右クリックして置換するか、自動設計の市販レンズ探索を使います。

特許例は計算経路や符号規約の検証に便利ですが、掲載された数値が現在の硝材名、コーティング、センサー、製造条件にそのまま対応するとは限りません。読み込み後の警告と出典注記を確認してください。

困ったとき

光線が像面で一点に集まらない

異常とは限りません。実光線は球面収差、色収差、コマ、非点収差などにより広がります。まず次を順に確認します。

  1. 像面・光線条件 → 像面を最良焦点へ追従をオンにする。
  2. 光学計算を押す。像面固定中なら解除するか、BFLを手入力する。
  3. 一次解析の「最終面からの近軸焦点」が実焦点になっているか確認する。
  4. 単レンズ1枚なら、平行光の近軸焦点に像面を置いても周辺光線や色の光線は一致しないことを理解する。
  5. 性能評価の縦収差とスポットで、実際の焦点ずれを確認する。
性能評価が更新されない

性能評価は設計変更だけでは再計算しません。タイトルに「*」が付いたら結果が古い状態です。解析実行を押してください。一次解析だけならメイン画面の光学計算または F5 です。

解析が失敗する、グラフが途中で切れる

有効径不足、絞りが小さすぎる、レンズ曲面の交差、全反射、極端な曲率や間隔を確認します。まずF値を暗くし、径と間隔を増やし、中心視野・主波長だけで成立するか切り分けます。

市販レンズを挿入・置換できない

左のカタログ表で対象行を先に選択してください。挿入は空気間隔または左端の「+」を右クリック、置換はレンズ本体を右クリックします。「不完全データ」の部品は設計へ使えません。

曲率や硝材が編集できない

カタログ品は処方保護中です。レンズ本体を選択し、カスタム化してから編集します。

レンズを削除したい

レンズ本体を右クリックしてレンズを削除、または選択項目パネルの削除を押します。面だけを削除する場合、カタログ品は先にカスタム化が必要で、1要素に最低2面は残ります。

自動設計に時間がかかりすぎる

局所方式、短い最大時間、少ない評価回数から始めます。メーカー、形状、各位置の候補数、使用レンズ数を絞り、変更不要な要素を固定します。自由探索と大域方式は候補空間が大きいため、成立条件を確認した後に使います。

前の状態へ戻したい

編集 → 元に戻すまたは Ctrl + Z を使います。大きな自動設計や置換の前には別名保存も行ってください。

この計算だけでは分からないこと

KiraKiraLensの性能評価は、入力した公称処方をOptilandで追跡した設計上の予測です。現物の完成性能を保証する測定ではありません。

  • 製造公差、偏心、傾き、組立誤差、温度変化はまだ含みません。
  • フレア、ゴースト、散乱、迷光、鏡筒内面反射は評価していません。
  • コーティング名は保存しますが、波長別透過率の計算にはまだ使いません。
  • センサーカバーガラスは設定できますが、画素構造、ローパス、マイクロレンズ、現像処理は含みません。
  • 相対照度、PSF、スルーフォーカスMTF、公差Monte Carloは今後の機能です。
購入前に確認すること カタログの型番、最新仕様、在庫、コーティング、外径・縁厚、保持方法、面品質、公差はメーカー資料で再確認してください。設計上よい候補でも、固定枠や絞り機構を含めて組み立てられなければ写真用レンズにはなりません。
